# 悲歌的小站

个人博客，随便写写，记录一些东西。

## 技术栈

纯静态 HTML + CSS + JS，部署于 GitHub Pages。

## 目录结构

```
├── index.html        # 首页（标签筛选 + 搜索 + 文章列表）
├── archive.html      # 归档页
├── changelog.html    # 更新日志
├── about.html        # 关于页
├── sitemap.xml       # 站点地图
├── posts/            # 文章
├── resources/        # 静态资源（插件、GIF、文档）
└── favicon.svg       # 站点图标
```

## 本地预览

双击 `index.html` 即可，无需构建步骤。
