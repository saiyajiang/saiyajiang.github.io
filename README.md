# 悲歌的小站

个人博客，随便写写，记录一些东西。

**访问地址：[saiyajiang.github.io](https://saiyajiang.github.io)**

## 主要板块

- **Blog** — 文章与摘抄，含标签筛选与全文搜索
- **Wiki** — 零散知识笔记（佛学典故 / 诗词 / 成语 / 字义辨析 / 医学心理 / 行话缩写 / 神话民俗 / 词源拾零 / 偏旁部首）
- **Changelog** — 站点更新日志
- **About** — 关于页

## 技术栈

纯静态 HTML + CSS + JS，部署于 GitHub Pages。

## 目录结构

```
├── index.html        # 首页（标签筛选 + 搜索 + 文章列表 + fortune 随机卡片）
├── archive.html      # 归档页
├── changelog.html    # 更新日志
├── about.html        # 关于页
├── sitemap.xml       # 站点地图
├── posts/            # 文章（摘抄等）
├── wiki/             # 知识笔记
├── assets/           # CSS / JS / 数据文件
├── resources/        # 静态资源（插件、GIF、文档）
└── favicon.svg       # 站点图标
```

## 本地预览

双击 `index.html` 即可，无需构建步骤。
