程序优先级

2026年8月16日 约 1 分钟阅读
#Windows #注册表 #系统技巧 #性能

需求

为某个程序固定设置 CPU、IO、页面优先级，避免每次启动后手动调整。

方案：注册表 PerfOptions

在注册表的 Image File Execution Options 下为程序添加 PerfOptions 项，设置优先级相关键值。

注册表路径与键值

HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options\程序全名\PerfOptions
"CpuPriorityClass"=dword:00000003
"IoPriority"=dword:00000003
"PagePriority"=dword:00000005

操作步骤

  1. 按 Win + R 输入 regedit 打开注册表编辑器
  2. 导航到 HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options
  3. 新建项，名称为程序全名（如 game.exe）
  4. 在该项下新建 PerfOptions 子项
  5. 在 PerfOptions 下新建三个 DWORD 值：CpuPriorityClass、IoPriority、PagePriority，按需填入数值

说明

  • CpuPriorityClass 常见值：1=空闲、2=低于正常、3=正常、4=高于正常、5=高、6=实时
  • 修改后需重启程序生效
  • 该路径为系统级（HKLM），对所有用户生效
💡

修改注册表前建议先备份该项；实时优先级（6）可能导致系统不稳定，谨慎使用。
