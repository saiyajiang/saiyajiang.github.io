雪花引擎相关设置

2026年8月16日 约 2 分钟阅读
#游戏 #性能优化 #SnowDROP #雪花引擎 #EAC

说明

雪花引擎（SnowDROP）相关设置。注意：必须至少运行过游戏一次才能访问这些设置。

图形配置文件

引擎与 SnowDROP 相同，配置文件位于：

文档\My Games\游戏名\graphic settings.cfg

关键参数：

["streamer dedicated budget"] = 512,
["streamer memory fraction"] = 0.1,
taa = 1,

参数说明

参数含义
streamer dedicated budget游戏从显卡中使用多少显存
streamer memory fraction自身值之外使用的显存百分比，0.1 表示游戏使用 10%
taa1 禁用无用的视觉性能消耗，0 完全禁用

注册表

路径：

HKEY_LOCAL_MACHINE\SYSTEM\ControlSet001\Services\EasyAntiCheat

将 ErrorControl 设置为 0。

有助于防止 EAC 每 2 秒左右不断发出报告，以防止游戏过程中出现挂起/卡顿。

服务

将 EasyAntiCheat 服务改为手动。

💡

修改注册表前建议先备份，或导出对应注册表项；服务改为手动后，游戏启动时仍会自动拉起 EAC。
